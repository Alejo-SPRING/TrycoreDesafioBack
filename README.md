## Documentación
1. Crea en mysql una db con el nombre: trycore_desafio
2. Ingresa a la carpeta del proyecto backend y abre una consola
3. Ejecuta en la consola el siguiente comando: comando para desplegar proyecto: ./mvnw spring-boot:run

Una vez ejecutados los pasos anteriores el back se desplegara y creara la base de datos, para acceder a la documentacion de las apis puedes usar el siguiente [http://localhost:8080/swagger-ui/index.html](link)
